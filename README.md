# Kara Public Service Hub

Crée le projet web DCOP en te basant sur le cahier des charges (version 10) joint pour implémenter la page d'accueil du Service Public : navbar avec logo de l'Université et mention DCOP, deux onglets uniques (Service Public et Service Privé), reproduction fidèle de https://univkara.tg/cooperation avec les 5 cartes d'accès rapide redirigeant vers le site mère dans un nouvel onglet, exclusion formelle de la section des actualités/opportunités, et reproduction du footer institutionnel officiel de l'Université de Kara.
